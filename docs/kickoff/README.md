# Kickoff prompts (historical)

These are the four task briefs the project started from, one per parallel build session
(agent core, sandbox, eval, API and deploy). They are kept unedited as a record of the original
plan, so they still describe the stubs and interfaces that existed before the branches were
merged. They are not documentation of the current code: for that, start at
[`../architecture.md`](../architecture.md). How the branches were merged, and what broke when
they were, is in [`../integration-notes.md`](../integration-notes.md).
